## Remaining merge blockers

1. Full Figma coverage is incomplete: see every Partial/Missing row below. Unsupported backend capabilities must remain inactive, per the user's instruction; they must not be fabricated from unrelated records. Several missing screens can still be built as inactive presentation, but a disabled tab alone is not equivalent to that screen.
2. Invited workspace selection: `team-invite` adds membership to the target organization, while the signup trigger also creates a personal organization. `AuthProvider` selects the oldest membership. The invitation acceptance UI has no target-organization contract to distinguish these. A user with both memberships may land in the personal workspace. Do not claim invitation acceptance into the intended workspace is verified.
3. Live acceptance is unavailable: Vercel preview redirects to Vercel login. No authenticated test workspace/account has been supplied. RLS, roles, recording authorization, upload/TXT analysis, reviewer writes, report generation, playbook writes, connector actions and billing/invoices have not been exercised against the deployed backend. User sign-in is required; passwords should not be pasted into chat.
