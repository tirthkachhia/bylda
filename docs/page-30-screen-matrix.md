### Service verification

- Browser verification used isolated responses and a range-enabled test recording. Live OAuth, invitation email, delivery, AI generation and provider sync require configured services and were exercised through fixture states where available.
- Rep practice persistence requires the committed coaching assignment practice migration. Scoped Ask Bylda streaming requires the committed memory-query function update. They have not been deployed from this branch.
- Agency setup uses multiple teams in one workspace. Existing team access policies scope managers to their agents. Separate agency organization hierarchies are outside the current data model.

The branch also includes a separate manager sign-in (`/auth/manager-sign-in`), manager entry (`/app/manager`), and agent management (`/app/settings?tab=teams`). These branch surfaces share the Page 30 shell and were captured as 57–59. The browser verified manager navigation to agent management and denied the manager landing page to a rep.
