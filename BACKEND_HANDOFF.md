# Page 30 intelligence and report data

The frontend uses existing workspace access, call insights, assignments, and saved coaching reports. The current report generator writes one report per rep and records the start and end dates of its rolling UTC window. The Daily and Weekly views identify one-day and seven-day windows from those dates. The Reports library keeps reports of every length.
